# Tu Cromi — Política de Privacidad

Sitio público con la política de privacidad de **Tu Cromi**, la aplicación de
transporte público de Santa Cruz de la Sierra, Bolivia.

- **URL publicada:** https://jerarka.github.io/tu-cromi-legal/
- **Fuente del texto:** [`index.md`](index.md) — fuente única. No existe otra copia.
- **Publicación:** GitHub Pages, rama `main`, carpeta raíz.

## Cómo actualizar

1. Editá `index.md` y actualizá la fecha de "última actualización".
2. Commit y push a `main`.
3. Pages republica en aproximadamente un minuto.

Este repositorio no contiene código de la aplicación.
